## 一、使用规则

- 每项决定一行，编号递增 `ADR-xxx`
- 推翻旧决定：旧行状态改为「❌ 已推翻」，「被替代」列填新编号；另起一行描述新决定
- 计划中但未定稿 / 未执行：状态「⏳ 待定」
- 每行尽量关联 git 提交，保证可追溯
- 变更发生时同步更新三处：交接文档 → 本文档 → 原文档修订记录
- 状态变化必须由用户确认，AI 不得擅自把「有效」改为「已推翻」

## 二、状态图例

| ⏳ 待定 | 已提出、未定稿或未执行 |

2. 状态变化必须由用户确认
3. 每季度或里程碑节点核对一次，清理「⏳ 待定」行
