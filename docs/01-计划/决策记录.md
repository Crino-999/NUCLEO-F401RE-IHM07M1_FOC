# 决策记录（ADR）—— 项目级「当前有效决定」索引

> 用途：本仓库所有设计决定、修正、推翻的唯一登记处。Codex 新会话以本文档「✅ 有效」行为设计基线。
> 状态：进行中 | 创建：2026-08-16 | 维护：Crino | 关联文档：学习总计划.md、项目状态与Codex协作交接.md

## 一、使用规则

- 每项决定一行，编号递增 `ADR-xxx`
- 推翻旧决定：旧行状态改为「❌ 已推翻」，「被替代」列填新编号；另起一行描述新决定
- 计划中但未定稿 / 未执行：状态「⏳ 待定」
- 每行尽量关联 git 提交，保证可追溯
- 变更发生时同步更新三处：交接文档 → 本文档 → 原文档修订记录
- 状态变化必须由用户确认，AI 不得擅自把「有效」改为「已推翻」

## 二、状态图例

| 状态 | 含义 |
|---|---|
| ✅ 有效 | 当前设计基线，新会话必须遵循 |
| ❌ 已推翻 | 历史决定，仅作背景，禁止沿用 |
| ⏳ 待定 | 已提出、未定稿或未执行 |

## 五、维护要求

1. 新增 / 推翻决定必须在同一变更的提交中完成（提交信息可附 `（ADR-xxx）`）
2. 状态变化必须由用户确认
3. 每季度或里程碑节点核对一次，清理「⏳ 待定」行
