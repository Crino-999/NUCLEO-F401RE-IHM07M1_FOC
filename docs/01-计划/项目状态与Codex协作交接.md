## 五、技术要点备忘

### 5.1 硬件平台

- **控制板**：NUCLEO-F401RE（STM32F401RET6, 84MHz, 512KB Flash, 96KB SRAM）
- **功率板**：X-NUCLEO-IHM07M1（L6230PD 三相无刷电机驱动器，最高 2.8A/45V）
- **电机**：2804 云台电机，7 极对，Y 形接法
- **结构**：两板叠加（NUCLEO 在上，IHM07M1 在下），通过 Morpho 排针连接，电机通过导线接到 J2 端子

### 5.2 L6230 驱动器关键特性

- DMOS 三相半桥驱动器，每相独立使能（EN1/EN2/EN3）
- 电荷泵供电（CPOUT 引脚监测）
- 诊断/刹车输入（DIAG/ENABLE/BKIN）
- 支持 1 路 PWM + 1 路 EN 或 2 路 PWM（高侧/低侧独立控制）模式

### 5.3 FOC vs 六步换相的硬件差异

- FOC 使用 3 路电流反馈（Curr_fdbk_PhA/B/C），J5/J6 设为三分流（1-2）
- 六步换相使用 BEMF 检测（BEMF1/2/3_sensing），J5/J6 设为单分流（2-3）
- 本工程当前配置为三分流 FOC 模式

### 5.4 参考手册对照

| 手册 | 编号 | 用途 |
|---|---|---|
| STM32 Nucleo-64 User Manual | UM1724 | Nucleo 板引脚映射（Table 16/29） |
| X-NUCLEO-IHM07M1 User Manual | UM1943 | IHM07M1 引脚映射（Table 3）、跳线配置 |
| Six-Step Firmware Library Guide | UM2124 | 六步换相固件 API |
| X-CUBE-MCSDK User Manual | UM1601 | MC Workbench 与 FOC 库 |

## 六、Codex 协作指引

### 6.1 Codex 可以做什么

- **代码审阅**：审查本人实现的 FOC 算法代码，指出问题并解释原因
- **原理讲解**：用通俗语言讲清概念，配合推导与图示
- **笔记梳理**：学习后协助生成结构化文档，供本人审阅
- **调试排错**：协助定位问题方向，分析波形/日志
- **工具链操作**：PDF 提取、git 操作、文件管理等

### 6.2 Codex 不可以做什么

- **不代写 FOC 核心算法代码**（坐标变换、SVPWM、PID、观测器等）
- **不虚构学习进度或实验数据**
- **不直接推送 git**；`commit` 前必须完成 8.6 隐私审查（L1+L2）并由本人终审确认

### 6.3 接手建议

1. 先阅读 `docs/01-计划/学习总计划.md` 了解完整路线图和约定
2. 阅读 `docs/01-计划/决策记录.md` 中「✅ 有效」行，作为当前设计基线
