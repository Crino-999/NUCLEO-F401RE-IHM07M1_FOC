# 实验记录：阶段 2 第 3 步 SVPWM 数值验证

> 状态：已验证（数值层，未上板驱动电机） | 日期：2026-10-11 | 关联：学习总计划-阶段 2、ADR-009、ADR-010 | 硬件：NUCLEO-F401RE + X-NUCLEO-IHM07M1

## 一、实验目的

验证 `user/svpwm.c` 的 `Svpwm_Calc()` 是否把给定的 αβ 参考电压正确映射为三相 PWM 比较值（CCR），覆盖整条数值链路：

扇区判断 → 作用时间计算 → 过调制限幅 → 比较点分配 → CCR 映射。

本步**只做数值验证**：不输出到电机，不接示波器，不验证功率级行为。

## 二、验证对象

| 文件 | 内容 |
|---|---|
| `NUCLEO-F401RE/user/svpwm.h` | `Svpwm_Calc(v_alpha, v_beta, vdc, Ts, ARR, &ccr_a, &ccr_b, &ccr_c)` 接口声明 |
| `NUCLEO-F401RE/user/svpwm.c` | 六步实现：X/Y/Z 计算 → 扇区号 N → TX/TY → 过调制限幅 → Ta'/Tb'/Tc' → 相序分配 → 输出三相占空比（初稿输出 CCR，同日简化，见 §十） |
| `NUCLEO-F401RE/Src/main.c` | `while(1)` 中 15° 步进的电角度扫描 + 重构校验 + 串口打印（每 200ms 一行） |

## 三、验证原理（重构不变式）

不读取算法内部中间量，而是**从输出 CCR 反推平均相电压，再变换回 αβ 与输入比对**：

```
dA = ccr_a / ARR,  dB = ccr_b / ARR,  dC = ccr_c / ARR     // 占空比
un = (dA + dB + dC) / 3                                     // 共模（零序）分量
(r_alpha, r_beta) = Clarke(dA - un, dB - un, dC - un)        // 差模分量
(e_alpha, e_beta) = (1.5 * v_alpha / vdc, 1.5 * v_beta / vdc)  // 期望值
err = sqrt((r_alpha - e_alpha)^2 + (r_beta - e_beta)^2)
```

**为什么这是有效判据**：占空比 → 平均相电压的关系为 `v_x = d_x · Vdc`（采样平均模型），减去均值后共模被消掉，Clarke(3/2 形式) 的幅值关系给出 `Clarke(d) = 1.5 · v_α / Vdc`。因此 `err ≈ 0` 等价于「输出的三相占空比所对应的差模相电压 = 目标 αβ 电压」。

**该判据为什么能覆盖扇区表**：`Cmp` 的相序分配决定各相占空比，而 Clarke 对这一分配敏感——TX/TY 计算、扇区判断、相序分配三张表中任何一处单独出错，都会破坏不变式使 `err` 显著非零。故 `err ≈ 0` 验证的是**整条链路的组合正确性**。

## 六、数据分析

### 6.1 重构不变式

24 个角度点 `err` 全部为 `0.000`。

`err` 以 `%5.3f` 打印，故实测 `err < 5×10⁻⁴`。理论残差上限由 CCR 取整（±0.5 LSB）决定：占空比量化误差 ≤ 0.5/2625 = 1.9×10⁻⁴，经 Clarke 放大后 `err ≤ 4.4×10⁻⁴`。**说明 `err` 的量级就是量化噪声，不是算法误差。**

以 θ=15° 为例按输出 CCR 反算：`r_alpha = 0.836381`（期望 0.836517，差 −1.4×10⁻⁴），`r_beta = 0.224011`（期望 0.224144，差 −1.3×10⁻⁴），`err ≈ 1.9×10⁻⁴`——正是三个 CCR 各自取整到整数所引入的残差。

### 6.2 全扇区覆盖

24 个点覆盖 0°~345°，α、β 的正负号组合全部出现，六个扇区均被扫到，且相邻扇区之间的 CCR 变化连续（无跳变、无溢出）。

### 6.3 手算对照（三点复核）

| θ | 内部扇区 N | TX / TY | T0 | CmpA/B/C | 手算 CCR | 实测 CCR |
|---|---|---|---|---|---|---|
| 15° | 3 → 扇区 1 | 0.7071 / 0.2588 | 0.0341 | 0.0085 / 0.3621 / 0.4915 | 2580 / 724 / 45 | 2580 / 724 / 45 ✅ |
| 120° | 1 → 扇区 2 | 0.8660 / 0 | 0.1340 | 0.4665 / 0.0335 / 0.4665 | 176 / 2449 / 176 | 176 / 2449 / 176 ✅ |
| 180° | 4 → 扇区 4 | 0 / 0.8660 | 0.1340 | 0.4665 / 0.0335 / 0.0335 | 176 / 2449 / 2449 | 176 / 2449 / 2449 ✅ |

物理层面自洽：θ=120° 时 Uref 在 +120°（= 基本矢量 U2 = 010），实测 B 相占空比最大、A/C 相最小，与「只有 B 相高」一致；θ=180° 时 Uref = −α（= U3 = 011），实测 A 相最小、B/C 相最大，一致。

### 6.4 打印的 `sec` 列 ≠ 算法内部扇区号（重要）

`sec` 列是 `(int)(theta_deg / 60) + 1`，**由扫描角反推的参考扇区**，不是 `Svpwm_Calc()` 的内部结果（`main.c` 注释已声明该点）。实测暴露了差异：

| θ | 打印 sec | 内部扇区（按 N 值反推） | 是否一致 |
|---|---|---|---|
| 0° | 1 | 6 | ❌ 差 1 |
| 60° | 2 | 2 | ✅ |
| 120° | 3 | 2 | ❌ 差 1 |
| 180° | 4 | 4 | ✅ |
| 240° | 5 | 4 | ❌ 差 1 |
| 300° | 6 | 6 | ✅ |

原因：扇区判断用的是严格比较 `X > 0 / Y > 0 / Z > 0`。在 θ = 0°/120°/240° 上恰好有 X=0 或 Z=0 或 Y=0，该分量被判为 0，矢量被归到相邻扇区。
**这不是缺陷**：边界矢量在两个相邻扇区中都可表示，且两种表示给出相同的 TX/TY 与 CCR（已用 θ=0° 验证：扇区 6 与扇区 1 均得 2449/176/176）。但如果后续引入非对称处理（死区补偿、零矢量非均分等），边界归属就会产生影响，需要重新审视。

### 6.5 线性区上限行为

θ=30°/90°/150°/… 处出现 CCR = 2625（= ARR，满占空比）与 CCR = 0（零占空比）。这正是 SVPWM 线性区上限的特征点——M = 1.0 时六边形内切圆与各扇区中线相切。
θ=0°/60°/… 等扇区边界处 CCR 未触及限幅（如 2449/176/176），与「边界点只用到单一基本矢量」的预期一致。

## 十、接口简化后的复测（同日）

初稿的 `Svpwm_Calc()` 把硬件细节也包了进来：接受 `Ts`、`ARR` 两个形参，直接输出 CCR。这是分层错误——SVPWM 是纯数学模块，不该知道 TIM1 的 ARR 是多少。同日简化为：

```c
/* 输入：v_alpha / v_beta / vdc（单位 V）
 * 输出：da / db / dc 三相【高侧开关的导通占空比】，0.0 ~ 1.0
 * 内部时间单位：一个 PWM 周期 = 1.0 */
void Svpwm_Calc(float v_alpha, float v_beta, float vdc,
                float *da, float *db, float *dc);
```

改动只在接口与归一化：`K = √3·Ts/vdc` → `K = √3/vdc`，限幅判据 `sum > Ts` → `sum > 1`，第 6 步由 `CCR = (Ts − 2·Cmp)·ARR/Ts` 改为 `duty = 1 − 2·Cmp`（钳位 `[0, 1]`）。占空比→CCR 的换算移到硬件层 `motor_control.c`（`CCR = duty × htim1.Init.Period`）。**算法本体（X/Y/Z、扇区表、TX/TY 表、比较点分配表）一字未动**；由于原实现里 `Ts` 一直被传 1.0，前 5 步与改前逐位等价。

### 结果

`err` 从 `1.9×10⁻⁴` 降到 `5.96×10⁻⁸ ~ 4.79×10⁻⁷`，**掉了约三个数量级**，正好对应去掉 CCR 取整量化的效果。现在这个残差是 float32 单精度的舍入极限（数值量级 ~1，机器 epsilon ~1.2×10⁻⁷），**不是算法误差**——数值层面已经没有可再压榨的余地。

更有说服力的是占空比数值与初稿 CCR 逐点对应：`duty × 2625 = 旧 CCR`（0.933×2625 = 2449、0.067×2625 = 176、0.500×2625 = 1313、1.000×2625 = 2625），说明接口简化是**数学等价**的，不是重新实现。扇形中点的极值组合（`1.000 / 0.500 / 0.000`）和扇区边界不触及限幅的现象也与初稿完全一致。

**§八 的结论继续成立**，且证据比初稿干净：六扇区全覆盖、24 点 `err` 到单精度极限、与手算三点一致。
