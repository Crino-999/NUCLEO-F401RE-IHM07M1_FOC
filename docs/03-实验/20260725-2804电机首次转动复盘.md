# 实验记录：2804 电机首次转动复盘

> 状态：待补充 | 日期：2026-07-25 | 关联：学习总计划-阶段0 | 硬件：NUCLEO-F401RE + X-NUCLEO-IHM07M1

## 一、实验目的

让 2804 无刷电机在 NUCLEO-F401RE + X-NUCLEO-IHM07M1 平台上转动起来，走通"下载工具链 → 生成工程 → 部署 → 调通"的完整流程。这是电机控制学习主线的第一个里程碑，也是理解 MC Workbench 工具链的起点。

## 二、背景：前期铺垫（正点原子板）

在换用 ST 开发板之前，已在正点原子板（STM32F103 + SimpleFOC mini 驱动板）上让同型号电机转过，时间线可从 `STM32F103` 仓库提交记录确认：

| 时间 | 事件 |
|---|---|
| 2026-07-20 22:13 | 配置 I2C 连接 AS5600 编码器，配置 PWM 引脚与使能引脚 |
| 2026-07-20 22:29 | AS5600 角度读取任务（FreeRTOS 任务每 200ms 读取打印） |
| 2026-07-21 00:30 | 开环电机控制（SVPWM + 速度/角度开环），开环强拖成功 |
| 2026-07-21 02:19 | 闭环初版（FOC + PID 级联） |
| 2026-07-21 17:50 | 闭环 v2（速度闭环，含低通滤波等完善） |

这段经历说明电机本体和传感器验证可行，但代码基于 SimpleFOC 移植、由 AI 协助完成，本人尚未掌握原理。本次改用 ST 官方工具链，目标是先掌握 MC Workbench 生成式开发流程。

## 六、操作步骤

1. 从 ST 官网下载并安装 MotorControl Workbench 及对应 SDK 包
2. 在 Workbench 中新建工程，选择 NUCLEO-F401RE + IHM07M1 组合
3. 配置电机参数与驱动板参数
4. 生成工程并编译
5. 烧录部署到开发板
6. 接线并上电，验证电机转动
