# docs 文档体系

本仓库以电机控制（FOC）为学习主线，承载于 NUCLEO-F401RE + X-NUCLEO-IHM07M1 平台。所有文档类内容统一存放于本目录，与代码工程分离管理。

## 目录导航

| 目录 | 用途 |
|---|---|
| `01-计划/` | 路线图、阶段计划、里程碑、决策记录 |
| `02-笔记/` | 按主题归档的学习笔记 |
| `03-实验/` | 上板实验记录（按时间命名） |
| `04-资料/` | 学习资源清单与索引 |
| `05-日志/` | 学习日志与周复盘 |

## 文档约定

- 命名：目录见各自 README，笔记 `主题-序号-标题.md`，实验 `YYYYMMDD-实验名.md`，日志 `YYYY-MM-DD-类型.md`
- 语言：全部使用中文
- 状态标注：计划与资料类文档在文件开头标注 `状态：进行中 / 待审阅 / 已完成`
- 每次学习完成后由 AI 协助梳理成结构化文档，本人审阅确认后归档
