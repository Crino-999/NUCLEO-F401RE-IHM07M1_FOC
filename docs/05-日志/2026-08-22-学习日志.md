## 今日完成

### 第 2 步：坐标变换模块实现与验证

在 `user/` 目录下新建 `transform.c/h`，实现 Clarke、Park、逆 Park、逆 Clarke 四个变换函数。

#### 变换公式

**Clarke（abc → αβ，3/2 形式）**：
```
iα = ia - (ib + ic) / 2
iβ = √3 · (ib - ic) / 2
```
此形式下 αβ 幅值 = 1.5 × 相电流幅值，dq 值同理。

**Park（αβ → dq）**：
```
id =  iα·cos(θe) + iβ·sin(θe)
iq =  iβ·cos(θe) - iα·sin(θe)
```

**逆 Park（dq → αβ）**：
```
vα = vd·cos(θe) - vq·sin(θe)
vβ = vd·sin(θe) + vq·cos(θe)
```

**逆 Clarke（αβ → abc）**：
```
va = vα
vb = (-vα + √3·vβ) / 2
vc = (-vα - √3·vβ) / 2
```

#### 接口设计

| 函数 | 用途 |
|---|---|
| `Transform_Clarke(ia, ib, ic, &iα, &iβ)` | 三相 → 静止正交系 |
| `Transform_Park(iα, iβ, sin, cos, &id, &iq)` | 静止 → 旋转系（Park 变换） |
| `Transform_InversePark(vd, vq, sin, cos, &vα, &vβ)` | 旋转 → 静止系（逆 Park） |
| `Transform_InverseClarke(vα, vβ, &va, &vb, &vc)` | 静止正交 → 三相（逆 Clarke） |

Park/逆Park 接收 sin/cos 而非角度，直接用 `Encoder_GetSinCos()` 输出，避免重复三角函数计算。

#### 验证方法

用模拟三相电流（I=1A，与真实电角度同步的余弦波）验证正向变换链路。串口每 50ms 打印 θe、iα、iβ、id、iq。

#### 验证结果

- id 恒定 = 1.50（= 1.5 × I，符合 3/2 形式 Clarke 的幅值放大）✅
- iq ≈ 0（±0.02 抖动，来自 3 次独立 I2C 读取的角度微小差异）✅
- iα、iβ 随 θe 正弦变化，互相正交 ✅

## 反思

- Clarke 变换有两种常见形式：等幅值（带 2/3 系数，dq 值 = 相电流幅值）和 3/2 形式（不带 2/3，dq 值 = 1.5×相电流幅值）。本次使用 3/2 形式（ST MCSDK 风格），只要正反变换配套就没问题。验证时需注意期望值是 1.5×I 而非 I。
- Park 变换的符号方向容易搞混。本次实现中 id 包含 `+iα·cos + iβ·sin`，iq 包含 `-iα·sin + iβ·cos`，验证结果 id 恒定 iq≈0 证明符号正确。
