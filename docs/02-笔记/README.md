# 02-笔记

本目录存放按主题归档的学习笔记，每次学习后由 AI 协助梳理、本人审阅确认后归档。

## 主题分类建议

| 子目录 | 内容 |
|---|---|
| `电机原理/` | 无刷直流电机、永磁同步电机、逆变电路原理 |
| `FOC算法/` | 坐标变换、SVPWM、PID 整定、观测器 |
| `MC-Workbench/` | ST MotorControl Workbench 工具链使用与工程解读 |
| `MATLAB仿真/` | Simulink 建模、控制算法仿真 |
| `总线协议/` | CAN、EtherCAT、串口等通讯协议 |

命名规范：`主题-序号-标题.md`，例如 `FOC算法-01-坐标变换与克拉克变换.md`（手写笔记电子化版本用 `.html`，图形以 SVG 重绘）

| 文件 | 说明 |
|---|---|
| `电机原理/三相电与电机模型-手写笔记电子化.html` | 手写笔记电子化：三相电、感应电动势、电机模型、RLC 电路（含 SVG 重绘图） |
